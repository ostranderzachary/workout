How to read this map

Each muscle is coloured by how much of its lifting goal you've done in the range above. The brighter the green, the closer you are; bright lime means the goal is met. Grey means nothing logged for that muscle yet.

An exercise counts a full set for the muscles it mainly works and half a set for the muscles that help. A bench press set is 1 set for chest and ½ for triceps and shoulders.

Tap a muscle to see its numbers and which exercises counted.
